# Hard to Focus

A responsive web project about concentration, distractions, and ways to improve focus.

The website supports multiple color themes and adapts to the user's system theme preferences.

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Design
- CSS Grid
- CSS Variables

## Features

- Light and dark themes
- Automatic theme based on system preferences
- Responsive layout
- Adaptive image gallery
- Accessible semantic markup
